If the value is greater than 0; this will limit the TOTAL number of builds (from any job) allowed on this agent. A Pipeline run counts as one build, however many node {} blocks it runs. When the threshold number of builds is reached, the agent takes no new builds (they wait in the queue, they are not aborted) and, once nothing is using it, it is recycled: the agent is disconnected. Use 0 to disable this feature.
