How the host is connected to, which decides what the other settings are.
  • vCenter, through the vSphere API: the usual way. Everything the plugin does is available.
  • Standalone ESXi host(s) over SSH: for ESXi hosts that have no vCenter (one, or several that are used together), and whose own API cannot be written to (as with the free license) or is too old. The plugin runs vim-cmd on the host. Only a part of what the plugin can do is available this way, and what is not says so.

    SSH has to be enabled on the ESXi host: in its web interface go to Host → Manage → Services, select TSM-SSH, and in its Actions menu choose Policy → Start and stop with host (so that it is available after a restart of the host), and Start (so that it is available now).
