The fingerprint of the SSH host key of the ESXi host (the short name of its key, as ssh-keygen -l shows it: SHA256:..., or an older MD5 one, 00:11:22:...). Only a host that presents this fingerprint is trusted. Show fingerprint asks the host which one it presents.

With "the fingerprint seen first" this is filled in by the first connection. Clear it to have the next connection be a first one again, after a change of the host's key that is expected.
