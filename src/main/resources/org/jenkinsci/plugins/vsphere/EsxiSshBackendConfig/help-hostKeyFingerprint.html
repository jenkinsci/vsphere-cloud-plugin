The fingerprint of the host key of the ESXi host, as ssh-keygen -l shows it (SHA256:...), or an older MD5 one (00:11:22:...). Only a host with this host key is trusted. Show host key asks the host which one it presents.

With "the host key seen first" this is filled in by the first connection. Clear it to have the next connection be a first one again, after a change of the host key that is expected.
