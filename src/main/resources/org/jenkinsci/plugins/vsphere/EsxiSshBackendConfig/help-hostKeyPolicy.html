Which host key to trust, so that it is the ESXi host that is talked to, and not something in between.
  • Only the host key with the fingerprint below (the default, and the safest): nothing is trusted until the fingerprint of the host's host key is given. Show host key and Test Connection show which one the host presents now, to put in the setting after checking that it is the host's own (for example on its console, or with ssh-keygen -l -f /etc/ssh/ssh_host_rsa_key.pub there).
  • The host key seen first: the host key that is presented the first time is trusted, and remembered in the fingerprint below; from then on only it is. A changed host key (a reinstalled host, or something in between) is refused, until the fingerprint is cleared. Only as safe as the first connection is.

    This makes Jenkins save its configuration by itself at the first connection, to keep the fingerprint: the configuration of the folder, for a cloud that is defined in a folder, otherwise the configuration of Jenkins.

  • Any host key: not secure; for hosts in a network that is safe.
A fingerprint that is given always has to match, whichever is chosen here.
