Which fingerprint to trust, so that it is the ESXi host that is talked to, and not something in between.
  • Only the fingerprint given below (the default, and the safest): nothing is trusted until the fingerprint of the host is given. Show fingerprint and Test Connection show which one the host presents now, to put in the setting after checking that it is the host's own (for example on its console, or with ssh-keygen -l -f /etc/ssh/ssh_host_rsa_key.pub there).
  • The fingerprint seen first: the fingerprint that is presented the first time is trusted, and remembered in the setting below; from then on only it is. A changed fingerprint (a reinstalled host, or something in between) is refused, until the setting is cleared. Only as safe as the first connection is.

    This makes Jenkins save its configuration by itself at the first connection, to keep the fingerprint: the configuration of the folder, for a cloud that is defined in a folder, otherwise the configuration of Jenkins.

  • Any fingerprint: not secure; for hosts in a network that is safe.
A fingerprint that is given always has to match, whichever is chosen here.
