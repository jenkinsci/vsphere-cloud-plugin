If the value is greater than 0, the agent is recycled after this many builds (from any job). A Pipeline run counts as one build, however many node {} blocks it runs, and it is counted on the first limited agent that runs one of them only.

When the number is reached, the agent takes no new builds: they wait in the queue, they are not aborted. What a run that is already counted on the agent needs is let through all the same (the next node {} blocks of that run, and the builds it starts), and runs beyond the limit. Once nothing is using the agent, it is recycled: the agent is disconnected, and the count starts again. A clone has no snapshot and no idle action, so this does not clean its virtual machine. The count is kept when Jenkins is restarted.

Agents with the Run-Once retention strategy are not recycled by this: they are terminated after each task. Use 0 to disable this feature.
