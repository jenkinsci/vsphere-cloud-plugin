(Optional, a whole number) Minimal free CPU as a percentage of the host's capacity (0-100) a host must have right now to be a candidate for automatic host selection, as on the vSphere Cloud, where the limits are described in detail.

Leave all four host limit fields of this call blank to use the limits of the vSphere cloud. If you set any of them, the four values here replace the cloud's limits as a whole for this call, and the ones left blank count as 0 (no limit). Setting all four to 0 therefore removes the limits for this call, whatever the cloud has configured.

Variables can be used where this is a build step.
