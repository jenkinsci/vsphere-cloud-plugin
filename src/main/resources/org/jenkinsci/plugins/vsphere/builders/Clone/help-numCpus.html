(Optional) The number of virtual CPUs to create the new VM with, set in the very same operation that creates it, rather than cloning at the source's size and reconfiguring afterwards. Leave blank to keep the source VM's (or template's) own value. Variables can be used.

When the "Require enough CPU cores"/"Require enough RAM" options are in effect, automatic host selection compares candidate hosts against this value instead of the source's.

The source VM's cores-per-socket setting is kept, so the number must be a multiple of it, or vCenter will refuse the request.
