Alternative to Device Label for the Edit and Remove actions; cannot be combined with it, and is not supported for Add. One-based (1 = first adapter), to match the numbering vSphere itself uses in labels like "Network adapter 1": selects the Nth network adapter in the device list vCenter itself returns for the VM (counting only network adapters, in that same order) -- not a raw PCI slot number shared with other device types, and not the (freely renameable) device label text itself.
