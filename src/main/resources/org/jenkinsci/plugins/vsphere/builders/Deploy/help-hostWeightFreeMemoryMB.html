(Optional, a whole number) How much a host's free RAM in MB counts when automatic host selection looks for the "most available" host, as on the vSphere Cloud, where the scoring is described in detail.

Leave all four host weight fields of this call blank to use the weights of the vSphere cloud. If you set any of them, the four values here replace the cloud's weights as a whole for this call, and the ones left blank count as 0. Setting all four to 0 gives the original ranking (the host whose busier resource, CPU or memory, is the least used by percentage), whatever the cloud has configured.

Only the proportions between the weights matter, so 1 and 1 means the same as 50 and 50. Variables can be used.
