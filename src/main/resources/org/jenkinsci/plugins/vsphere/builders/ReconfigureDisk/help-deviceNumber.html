Alternative to Device Label; cannot be combined with it. Zero-based.
  • Add: names the new disk's file "<vm>_<N>", the same convention used when no name is given (fails if a disk with that name already exists).
  • Edit/Remove: selects the Nth disk (counting only disks, in the same order vCenter itself returns them) rather than matching a name or address -- if you need a specific controller/unit instead, use Device Label with a moniker like "SCSI(0:2)" or "IDE(1:0)".
