(Optional, a whole number) A host with less than this much free CPU, in MHz, is kept off the list of candidates for automatic host selection, however it would otherwise rank. This is a limit on how much load is too much, as opposed to the host weights, which only decide which of the acceptable hosts is preferred.

Zero (the default) switches this limit off. It is an absolute amount, which suits farms of similar hosts; see the percentage limit for mixed farms. All four limits can be combined: a host must satisfy every one that is set. A host whose usage statistics are unknown cannot be shown to satisfy a limit, and is left out.

If the limits leave no host at all, the clone or deploy fails, unless it is told to wait for a host to free up (see Seconds to wait for a host within the limits). The build console log lists every host ruled out and why.
