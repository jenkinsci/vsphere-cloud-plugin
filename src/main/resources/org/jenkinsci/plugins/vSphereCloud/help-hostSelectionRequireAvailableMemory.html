(Optional, off by default) When automatic host selection is in use (a "Host Selection Mode" is set and no explicit host is given), only consider candidate hosts that have at least as much memory free right now as the VM being created is configured with, so the hypervisor does not have to start swapping to make room for it.

This differs from "Require enough RAM", which compares the memory installed in the host. This one uses the host's current memory usage as reported by vCenter, which changes by the minute and lags a little, so several VMs created at once can still land on the same host. A host whose memory usage is unknown does not qualify.

If no candidate host qualifies, a message is logged and placement is left to vCenter, as when no usable candidate host exists at all. It has no effect when an explicit host is given.

This is the default for every template and build step using this cloud; each of them can override it either way ("Yes"/"No"), or leave it on "inherit".
